# Дополнительные учебные файлы

Эти три синтетических DOCX соответствуют разделу «Ещё три рабочих задачи» на странице первой пары. Перед загрузкой в ИИ слушатель выбирает один файл и использует запрос из соответствующего задания.

`<source>…</source>` в запросах означает границы вставленного текста. Если файл уже прикреплён к чату, достаточно написать его название и указать: «используй только этот приложенный файл».
