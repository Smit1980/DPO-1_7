Новая первая пара: 90 минут, две последовательные половины 45+45. Опубликована на GitHub Pages: https://smit1980.github.io/DPO-1_7/web/first_pair_val.html. Исходные страницы сохранены.

На титульном экране показаны обе темы цикла 90+90 минут. Текущая страница раскрывает первую пару. Файл 00.png стоит первым, файлы 1.png … 10.png закреплены за соответствующими этапами. Все изображения считываются прямо из assets/slides после обновления страницы.

Каноническое содержание: tools/lesson_content.py; дополнительные задания: practice.json с расширением при сборке. Проверка браузера: qa/check.cjs, результат qa/report.json. Раздатка: data/razdatka_pair1.zip. Конспект: teacher/konspekt_pair1.docx и web/konspekt_pair1.html. Для раздела «Ещё три рабочих задачи» добавлены автономные синтетические DOCX в data/additional-cases; страница объясняет, как использовать рамку <source>…</source> или прикреплённый файл.
